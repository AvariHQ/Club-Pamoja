# SEO

## Implemented
- **Per page:** unique `<title>` (`{Page} | Club Pamoja`; the home page uses a descriptive title), unique meta description, canonical URL (from `PUBLIC_SITE_URL`), Open Graph and Twitter card tags, and a 1200×630 OG image (`public/og-default.png`, regenerated by `scripts/make-og.mjs`).
- **Structured data (JSON-LD):** `Organization` and `WebSite` on every page, `BreadcrumbList` on every interior page, and `FAQPage` on `/faq/` (built from the same data as the visible answers). There are **no** review or rating schemas and no invented organization data (no address, phone or founding date until confirmed).
- **Crawlability:** fully static HTML, body copy in the markup, one H1 per page with ordered headings, descriptive internal links, breadcrumbs.
- `sitemap-index.xml` is generated by `@astrojs/sitemap` and excludes `/sign-in/` and 404. `robots.txt` references the sitemap.
- `/sign-in/` and 404 are `noindex`.
- Trailing-slash URLs are enforced (`trailingSlash: 'always'`).

## Before launch
1. Set `PUBLIC_SITE_URL` to the production origin.
2. Add 301 redirects from every old WordPress URL (crawl the live site first) in `astro.config.mjs`.
3. Submit the sitemap in Google Search Console and Bing Webmaster Tools.
4. When confirmed, add `email`, `address` and `foundingDate` to the Organization schema in `BaseLayout.astro`.
